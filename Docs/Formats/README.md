# File Format Specs

This folder collects documentation for engine resource and asset file formats.

- [3DO](3DO.md): text model files loaded from `3do\` or `hi3do\`.
- [AI](AI.md): AI-class text files loaded from `misc\ai\`.
- [GCF](GCF.md): binary font-metrics files paired with `.mat` atlases.
- [KEY](KEY.md): text animation keyframe files loaded from `3do\key\`.
- [MAT](MAT.md): binary material texture files loaded from `mat\`.
- [PAR](PAR.md): particle definition files loaded from `misc\par\`.
- [PUP](PUP.md): puppet-class text files loaded from `misc\pup\`.
- [SND](SND.md): sound-class text files loaded from `misc\snd\`.
- [SPR](SPR.md): text sprite-definition files loaded from `misc\spr\`.
- [UNI](UNI.md): text string-table files loaded from `misc\`.
