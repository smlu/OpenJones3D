## BMP Test Vectors

- `valid_2x2_24bpp.bmp` is a synthetic minimal bottom-up BI_RGB 24 bpp BMP.
- `bmpsuite_g_rgb24.bmp` is `g/rgb24.bmp` from BMP Suite 2.8 by Jason Summers:
  https://entropymine.com/jason/bmpsuite/
- `bmpsuite_g_rgb24pal.bmp` is BMP Suite `g/rgb24pal.bmp`, a valid 24-bit BMP
  with a palette before the pixel data.
- `bmpsuite_b_badheadersize.bmp` is BMP Suite `b/badheadersize.bmp`, an
  invalid BMP with an unsupported DIB header size.
- `bmpsuite_b_badbitcount.bmp` is BMP Suite `b/badbitcount.bmp`, an invalid
  BMP with an impossible bit count.
- `bmpsuite_b_reallybig.bmp` is BMP Suite `b/reallybig.bmp`, an invalid 24-bit
  BMP with dimensions that force image-size rejection.
- `bmpsuite_b_shortfile.bmp` is BMP Suite `b/shortfile.bmp`, an intentionally
  malformed short BMP used as a rejection vector.
- `bmpsuite_q_rgb24png.bmp` is BMP Suite `q/rgb24png.bmp`, an unsupported BMP
  variant with embedded PNG data.

BMP Suite's README states that image files generated by the suite are public
domain except for embedded ICC profiles. These selected fixtures do not embed
ICC profiles.
